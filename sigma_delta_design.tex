\section{Overview}
\label{section:overview}

In the sigma-delta ($\Delta\Sigma$) ADC topology, a quantizer produces a stream of coarse 1-bit decisions, each of which is fed back through a 1-bit DAC into the loop's cascaded integrators, shaping the input to subsequent decisions. 
The block diagram of the $\Delta\Sigma$ ADC is shown in figure~\ref{fig:block_diagram}.

The ones density of the bitstream, denoting the proportion of quantizer decisions resolved to logic 1 within a given interval, is a monotonic function of the input voltage centered around the comparator's reference voltage, $V_{\mathrm{ref}}$.
Because resolution is built up from many decisions rather than a single high-precision comparison, a $\Delta\Sigma$ ADC trades conversion latency for resolution relative to a SAR ADC, which resolves a full-precision word in a single conversion cycle.
This report documents a second-order continuous-time $\Delta \Sigma$ ADC, designed and tested in
LTspice before discrete breadboard implementation using physical components. The target specifications
for the design are listed in table~\ref{tab:specs}.

\begin{table}[H]
    \centering
    \caption{Design Specifications}
    \label{tab:specs}
    \begin{tabular}{@{}ll@{}}
        \toprule
        Parameter & Value \\
        \midrule
        Signal Bandwidth & \qty{200}{\hertz} \\
        Oversampling Ratio (OSR) & 128 \\
        Sample Rate & \qty{51.2}{\kilo\hertz} \\
        \bottomrule
    \end{tabular}
\end{table}

The cascade-of-integrators feedback (CIFB) topology is accomplished using the dual op-amp MCP6002, 
followed by the LM393 comparator acting as the 1-bit quantizer, with the quantizer's decision fed back through two separately-signed 1-bit DAC paths, one direct and one inverted, to correctly close negative feedback around each integrator stage.
The system has been fully brought-up and its closed-loop dynamics are verified and stable. A five-point input sweep from $\qty{1.23}{V}$ to $\qty{3.26}{V}$ correctly demonstrated
a monotonic trend between effective ones density and input voltage without latching to either rail.

Achieving this correct behavior is the subject of this report. This report documents the debugging process through which the $\Delta\Sigma$ ADC design was built on physical hardware, especially
diagnosing and fixing a sign error which mistakenly caused positive feedback, and several instrumentation artifacts that initially presented as hardware faults. One known limitation remains open: occasional long runs of identical bits (limit cycles)
near mid-scale, an expected consequence of the unclocked, free-running quantizer, with a known synchronous fix using the 74HC74 identified but deferred due to scope.
